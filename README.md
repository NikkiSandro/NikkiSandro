## Как я веду проект

Проект обычно начинается с задачи на языке бизнеса: запустить рассылки, записывать клиентов на ремонт или перенести нужный процесс в бота. Я выясняю, как все устроено сейчас, продумываю путь пользователя и подбираю стек.

Код собираю с помощью AI, затем проверяю ключевые сценарии, запускаю тесты и исправляю слабые места. Работаю со всем продуктом целиком: интерфейсом, серверной частью, базой данных, интеграциями и развертыванием.

## С чем работаю

- **Frontend:** Vue, React, TypeScript, JavaScript, Vite
- **Backend:** Python, PHP, FastAPI, REST API, фоновые задачи
- **Боты и AI:** Telegram, MAX, aiogram, OpenClaw, AI agents
- **Данные и интеграции:** MySQL, PostgreSQL, 1С, Bitrix24, внешние API
- **Рабочий процесс:** Git, GitHub Actions, Docker, тесты, статический анализ
