# Система клиентских коммуникаций: Sender и четыре бота для Telegram и MAX

Пять связанных компонентов для двух розничных проектов: веб-сервис Sender и по два клиентских бота в Telegram и MAX. Через ботов покупатели регистрируются, работают с программами лояльности и получают сообщения, а команда управляет аудиторией, контентом и рассылками из одной панели.

## Что входит в систему

| Sender | Четыре клиентских бота |
| --- | --- |
| Рассылки и планирование | Telegram и MAX для двух проектов |
| Единая клиентская база | Регистрация и проверка данных через 1С |
| Сегментация и аналитика | Программы лояльности и личные разделы |
| Редактор текстов ботов | Маршрутизация по источникам и агентам |
| Коды подтверждения | Акции, магазины, каталоги и поддержка |
| Журнал ошибок и изменений | Продолжение незавершенных сценариев |

## Sender

Sender дает команде одно рабочее место для всех четырех каналов.

- **Рассылки.** Сообщение можно собрать из текста, кнопок, ссылок, изображений и документов. Кампания отправляется сразу или по расписанию, а статус сохраняется для каждого получателя.
- **Аудитория.** Клиенты из Telegram и MAX объединяются по номеру телефона. Сегменты собираются по проекту, каналу, источнику, активности, регистрации и участию в программах.
- **Аналитика.** В сервисе видны рост базы, отправки, доставка, клики, CTR, коды подтверждения и ошибки. Показатели можно сравнивать по периодам, проектам и каналам.
- **Управление ботами.** Тексты, кнопки и ссылки редактируются с мобильным предпросмотром. Изменения применяются без нового релиза, предыдущую версию можно вернуть.
- **Контроль проблем.** Ошибки регистрации, обмена с 1С и доставки попадают в общий журнал. Команда видит контекст сбоя, затронутого клиента и статус исправления.
- **Сервисные коды.** 1С передает номер и одноразовый код. Sender последовательно проверяет доступные каналы, отправляет сообщение и возвращает результат каждой попытки.
- **Доступы.** Авторизация связана с Bitrix24, права сотрудников ограничивают критичные действия.

## Четыре бота, два проекта, разные клиентские сценарии

### «Чистая Планета»

Боты помогают покупателю зарегистрироваться в программе лояльности, посмотреть баланс и историю бонусов, узнать об акциях и магазинах, изменить профиль или обратиться в поддержку. Если регистрация прервалась, бот сохраняет шаг и помогает продолжить позже.

После получения номера бот проверяет клиента в 1С. Новый покупатель проходит полную регистрацию, клиент с незаполненным профилем отвечает только на недостающие вопросы, а владелец карты сразу получает доступ к личным разделам.

### «Планета Электро / Юником»

Боты обслуживают розничных и оптовых покупателей. Помимо регистрации и общих клиентских разделов, в них работают отдельные сценарии программ «СПЕЦ» и «Новосел»: подключение, условия, персональные данные программы, каталоги и материалы.

### Идентификация сценария по ссылке

Короткий код в стартовой ссылке связан с источником, рекламной кампанией или агентом в 1С. Бот проверяет этот код и открывает подходящий сценарий: обычную регистрацию, нужную программу или уже доступный клиенту раздел.

Источник первого обращения сохраняется, а агент фиксируется отдельно для конкретного действия. Повторный запуск или неизвестная ссылка не стирают уже собранные данные.
